# 🎮 Tic Tac Toe

A modern Tic Tac Toe game built with **HTML, CSS, and Vanilla JavaScript** featuring both **Single Player** and **Dual Player** modes, responsive design, and interactive sound effects.

## 🎯 How to Run Locally

Clone the repository

```bash
git clone https://github.com/Gargi0117/tic-tac-toe.git
```

Navigate to the project folder

```bash
cd tic-tac-toe
```

Open `index.html`

or run with **Live Server** in VS Code.

## 🎮 Game Rules

- Player **O** always starts first.
- Choose either:
  - 👤 Single Player
  - 👥 Dual Player
- Match three symbols horizontally, vertically, or diagonally to win.
- If all cells are filled without a winner, the game ends in a draw.
